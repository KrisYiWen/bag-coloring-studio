# Bag Coloring Studio 包包敷色工作台

把包袋照片做成"可点选换面料"的线稿工作台。

## 效果

上传一张包袋照片，自动生成线稿，把包拆成可点选的区域，每个区域可以单独换颜色、换面料，最后导出成品图。

示例：`demo/demo.html`（用 `demo/before.jpg` 生成的工作台，下载后用浏览器打开就能试）

## 安装

1. 下载本仓库 zip
2. 解压后把 `bag-coloring-studio` 文件夹放到豆包的技能目录里
3. 重启豆包，传一张包的照片就能用

## 怎么用

1. 传一张包的照片
2. 选择"直接做完"或"先看线稿"
3. 等几秒，包包敷色工作台就生成了
4. 点选区域，再点颜色或面料，就能换色换面料

## 支持的包型

- 托特包、帆布收纳篮
- 翻盖斜挎包、链条包
- 水桶包、抽绳包
- 马鞍包、腋下包、法棍包
- 双肩包、硬壳手提包
- 云朵包、枕头包、hobo 软包
- 草编包、编织包
- 圆筒包、波士顿包

## 不支持

- 衣服、鞋子、帽子
- 需要像素级精确复刻的场景（这个是"画册档"，线稿是重新画的，不对位）

## 原理

- 线稿用生图模型生成（不是算法提取），保持照片的视角和比例
- 用连通域分析把线稿拆成独立区域
- 每个区域单独渲染颜色/面料，支持导出 PNG
