# 失败处理

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 区域糊成一片 / 未分区处漏白 | 线稿断线 | 重生成时补"线条干净闭合、无断线"；仍不行就按实际块数降级交付 |
| 结构分区 = 2 块 | 线稿断得厉害，或整张图只有一条外轮廓 | 按 preflight 的 hints 补结构线重生成一次；再不行按实际块数降级交付 |
| 结构分区 < 2 块 | 线稿完全不可用，blocked 状态 | 禁止降级交付，必须重生成；第二次仍 blocked 时停止并告知用户线稿不可用 |
| 结构分区 > 30 块 | 阈值过松，印花/纹理被当成结构件 | 提高 `--min-area-pct`；或提示词里再强调"不要纹理/花纹"重生成 |
| 有分区贴到画面边缘 | 主体没切干净（整页截图、带文字） | 重生成时要求"只画包体，不要背景" |
| 体检 verdict=regenerate | 结构线不够 / 提手没闭合 / 主体贴边 | 按 `hints` 补对应那句话重生成（最多 1 次、总量 2 次）；仍不过就按实际块数降级交付，别硬凑 |
| 体检 verdict=blocked | 墨迹严重超标 / 背景严重不足 / 分区少于 2 块 | 禁止降级交付，必须重生成；第二次仍 blocked 时停止并告知用户线稿不可用 |
